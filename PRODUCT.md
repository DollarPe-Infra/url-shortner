# Product

## Register

product

## Platform

web

## Users

Internal DollarPe team (ops/engineering). They manage shortened links, users, and domains for company URL shortening. Context: at a desk, in a task, often for extended sessions. Fluent with modern dev tools (Linear, Stripe dashboard, terminals).

## Product Purpose

A self-hosted URL shortener (Kutt fork) branded for DollarPe. The admin dashboard is the primary surface: search, filter, create, ban, and delete links/users/domains. Success = an operator finds and acts on any link in seconds, and the tool feels trustworthy enough to not double-check.

## Brand Personality

Precise, calm, operational. "Dark control room": high data density, quiet surfaces, one green accent. The tool disappears into the task.

## Anti-references

- Crypto-dashboard neon: glows, gradient buttons, saturated everything.
- Glassmorphism panels, decorative blur.
- Consumer-friendly bubbly SaaS (the current Kutt look — rounded gradient buttons, pastel blue).

## Design Principles

1. **Density is respect** — internal operators want rows on screen, not whitespace theater.
2. **Green means act** — DollarPe green marks primary actions, selection, and live status only; never decoration.
3. **State over choreography** — motion conveys state changes (150–250ms); no page-load sequences.
4. **Same vocabulary everywhere** — one button shape, one form-control style, one icon set across admin, settings, stats, auth.
5. **Earned familiarity** — standard affordances (tables, tabs, dialogs) done crisply; no invented controls.

## Accessibility & Inclusion

WCAG AA contrast on dark surfaces. `prefers-reduced-motion` respected. Visible focus states throughout.
